## 🚀 Getting Started

Clone the project

```bash
git clone https://github.com/HediyeSeza/lumen-notes.git
```

Go to the project directory

```bash
cd lumen-notes
```

Install dependencies

```bash
npm install
```

Run development server

```bash
npm run dev
```
